# Bidra

Vi set pris på forslag, feilrapportar og kodebidrag! Opprett gjerne ei issue
eller ta kontakt med prosjektgruppa for å drøfte ei endring. Då kan vi saman
avklare behov, omfang og vidare arbeid.

Når vi blir samde om å gå vidare med eit kodebidrag, opprettar Digdir ei Jira-sak
og deler Jira-ID-en. Digdir går gjennom løysinga og samarbeider gjerne med
bidragsytaren om eventuelle justeringar.

Har du funne ei mogleg sikkerheitssårbarheit? Ikkje opprett ei offentleg issue
eller PR. Sjå [security.md](.github/security.md) for korleis du varslar oss.

## Pull requests

- Signer alle commits i PR-en. GitHub skal vise dei som verifiserte (`Verified`).
- Avtal endringa med prosjektgruppa og bruk Jira-ID-en du får tildelt.
- Bruk tittelformatet `<JIRA-ID>: <kort norsk tittel>`.
- Følg kodestilen og mønstra som er etablerte i prosjektet og den aktuelle
  applikasjonen.
- Skriv eller oppdater testar som dekker endringa, og køyr relevante testar
  før du sender PR.
- Beskriv kort kva som er endra, kvifor, og kva testar du har køyrt.
- Ikkje legg passord, nøklar eller andre løyndomar i koden eller PR-en.

Alle PR-ar blir gjennomgått av Digdir. Vi vurderer løysinga saman med
bidragsytaren før vi avgjer om ho skal takast inn.
